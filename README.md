### 1. Постановка задачи

> Напишите программу на Java, которая выполняет следующие действия
> с двумерным массивом температур:
> 1. Считывает с консоли размеры массива N и M, затем элементы
> массива размером N × M, где каждый элемент представляет температуру в точке с координатами (x, y).
> 2. Переставляет строки массива в порядке возрастания средней температуры в строке. Если средние температуры равны, сравнивает
> максимальные температуры строк (если равны, сохраняет исходный порядок).
> 3. Находит и выводит максимальную температуру и координаты точки, в которой она зафиксирована.
> 4. Выводит элементы массива в виде тепловой карты, заменяя температуры на символы, соответствующие их диапазону (например, ‘*’
> для низких температур, ‘’ для высоких).
> 5. Вычисляет и выводит разницу между максимальной и минимальной температурами в массиве.

 
Программа получает размеры двумерного массива N и M, а затем N × M температур. Необходимо отсортировать строки по возрастанию средней температуры. Если средние температуры равны, сравнить максимальные значения строк. Если оба значения равны, сохранить первоначальный порядок строк. Затем найти максимальную температуру и её координаты, построить тепловую карту из пяти символов и вывести разность максимальной и минимальной температур.
 
Задачу можно разделить на пять подзадач:
 
1. Ввод и заполнение двумерного массива.
2. Вычисление суммы и максимума каждой строки.
3. Сортировка строк по двум условиям.
4. Поиск максимальной и минимальной температур.
5. Построение тепловой карты и вывод результатов.
 
### 2. Входные и выходные данные
 
#### Данные на вход
 
Программа получает два положительных целых числа
и значения температур.
 
Температуры считаются вещественными числами.
Они могут быть положительными, отрицательными
или равными нулю.
 
| Переменная | Тип | Минимальное значение | Максимальное значение |
|---|---|---|---|
| n (строки) | int | 1 | 2^31 - 1 |
| m (столбцы) | int | 1 | Не задано в условии |
| T[i][j] | double | Не задано | Не задано |
 
Размеры массива также ограничены доступной памятью.
 
Для ввода дробной части используется точка.
 
#### Данные на выход
 
Программа выводит максимальную температуру,
координаты первого найденного максимума
в отсортированном массиве, тепловую карту
и разность максимальной и минимальной температур.
 
| Выходные данные | Тип | Значения |
|---|---|---|
| Максимальная температура | double | Зависит от ввода |
| Номер строки максимума | int | От 1 до N |
| Номер столбца максимума | int | От 1 до M |
| Тепловая карта | char | *, o, +, -, . |
| Разность температур | double | Неотрицательное число |
 
### 3. Выбор структуры данных
 
Для решения задачи используются двумерный массив
температур, дополнительные одномерные массивы
и несколько обычных переменных.
 
| Переменная | Тип в Java | Назначение |
|---|---|---|
| n | int | Количество строк |
| m | int | Количество столбцов |
| temperature | double[][] | Массив температур |
| sum | double[] | Суммы температур строк |
| rowMax | double[] | Максимумы строк |
| max | double | Максимум всего массива |
| min | double | Минимум всего массива |
| x | int | Индекс строки максимума |
| y | int | Индекс столбца максимума |
| signs | char[] | Символы тепловой карты |
| level | int | Номер символа тепловой карты |
 
Тип double выбран для температур, так как они
могут иметь дробную часть.
 
Двумерный массив позволяет хранить температуры
по строкам и столбцам.
 
Массивы sum и rowMax помогают сортировать строки
без повторного вычисления их характеристик.
 
### 4. Алгоритм
#### Математическая модель
 
**1. Сумма температур строки**
 
S<sub>i</sub> = T<sub>i,0</sub> + T<sub>i,1</sub> + ... + T<sub>i,m-1</sub>
 
Складываем все температуры одной строки.
 
**2. Средняя температура строки**
 
A<sub>i</sub> = S<sub>i</sub> / m
 
Здесь m - количество столбцов.
 
Так как количество столбцов во всех строках одинаковое, для сортировки достаточно сравнивать суммы строк.
 
**3. Максимальная температура строки**
 
R<sub>i</sub> = max(T<sub>i,0</sub>, T<sub>i,1</sub>, ..., T<sub>i,m-1</sub>)
 
Если суммы двух строк равны, сравниваем их максимумы.
 
Строки переставляются в двух случаях:
 
1. Если S<sub>i</sub> > S<sub>i+1</sub>.
2. Если S<sub>i</sub> = S<sub>i+1</sub> и R<sub>i</sub> > R<sub>i+1</sub>.
 
Если суммы и максимумы равны, строки сохраняют первоначальный порядок.
 
**4. Максимальная и минимальная температуры массива**
 
T<sub>max</sub> = наибольшая температура массива
 
T<sub>min</sub> = наименьшая температура массива
 
**5. Разность температур**
 
D = T<sub>max</sub> - T<sub>min</sub>
 
**6. Тепловая карта**
 
Диапазон от минимальной до максимальной температуры делится на пять равных частей.
 
Ширина одного диапазона:
 
h = (T<sub>max</sub> - T<sub>min</sub>) / 5
 
Номер диапазона для каждой температуры:
 
level = (int)((T<sub>i,j</sub> - T<sub>min</sub>) * 5 / (T<sub>max</sub> - T<sub>min</sub>))
 
Здесь (int) означает, что дробная часть результата отбрасывается.
 
Уровням соответствуют следующие символы:
 
| Уровень | Символ |
|---|---|
| 0 | * |
| 1 | o |
| 2 | + |
| 3 | - |
| 4 | . |
 
Если level = 5, заменяем его на 4, так как индексы массива символов находятся в диапазоне от 0 до 4.
 
Если T<sub>max</sub> = T<sub>min</sub>, всем элементам присваивается уровень 0, чтобы избежать деления на ноль.

 
#### Алгоритм выполнения программы
 
1. **Ввод данных**
 
   Программа считывает количество строк n
   и столбцов m.
 
   Если хотя бы один размер неположительный,
   выводится сообщение об ошибке.
 
2. **Создание массивов**
 
   Создаётся двумерный массив temperature.
 
   Также создаются массивы sum и rowMax,
   содержащие информацию о каждой строке.
 
3. **Заполнение массива**
 
   С помощью двух вложенных циклов for
   вводятся все температуры.
 
   Одновременно вычисляется сумма
   и максимальное значение каждой строки.
 
4. **Сортировка строк**
 
   Программа использует метод пузырька.
 
   Сначала сравниваются суммы двух соседних строк.
 
   Если сумма первой больше, строки
   меняются местами.
 
   Если суммы равны, сравниваются максимумы.
 
   Вместе со строками переставляются элементы
   массивов sum и rowMax.
 
   При полном равенстве строки не меняются
   местами.
 
5. **Поиск максимума и минимума**
 
   Программа проходит по отсортированному массиву.
 
   Если найдена температура больше max,
   обновляется максимум и запоминаются координаты.
 
   Если найдена температура меньше min,
   обновляется минимум.
 
6. **Построение тепловой карты**
 
   Для каждой температуры определяется уровень
   от 0 до 4.
 
   Затем выводится соответствующий символ
   из массива signs.
 
7. **Вывод результата**
 
   Программа выводит максимум, координаты,
   тепловую карту и разность max - min.
 
### 5. Программа
 
Программа написана на языке Java.
 
Для ввода используется Scanner,
для вывода используется PrintStream.
 
```java
import java.io.PrintStream;
import java.util.Scanner;
 
public class Main {
    public static Scanner in = new Scanner(System.in);
    public static PrintStream out = System.out;
 
    public static void main(String[] args) {
        // Вводим количество строк и столбцов
        int n = in.nextInt();
        int m = in.nextInt();
 
        // Проверяем размеры массива
        if (n <= 0 || m <= 0) {
            out.println("Размеры массива должны быть положительными.");
            return;
        }
 
        // Создаём массивы
        double[][] temperature = new double[n][m];
        double[] sum = new double[n];
        double[] rowMax = new double[n];
 
        // Вводим температуры
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                temperature[i][j] = in.nextDouble();
 
                // Находим сумму строки
                sum[i] += temperature[i][j];
 
                // Находим максимум строки
                if (j == 0 || temperature[i][j] > rowMax[i]) {
                    rowMax[i] = temperature[i][j];
                }
            }
        }
 
        // Сортируем строки методом пузырька
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
 
                // Сравниваем суммы, затем максимумы
                if (sum[j] > sum[j + 1] ||
                    (sum[j] == sum[j + 1] &&
                     rowMax[j] > rowMax[j + 1])) {
 
                    // Меняем местами строки
                    double[] tempRow = temperature[j];
                    temperature[j] = temperature[j + 1];
                    temperature[j + 1] = tempRow;
 
                    // Меняем местами суммы
                    double tempSum = sum[j];
                    sum[j] = sum[j + 1];
                    sum[j + 1] = tempSum;
 
                    // Меняем местами максимумы строк
                    double tempMax = rowMax[j];
                    rowMax[j] = rowMax[j + 1];
                    rowMax[j + 1] = tempMax;
                }
            }
        }
 
        // Начальные значения максимума и минимума
        double max = temperature[0][0];
        double min = temperature[0][0];
        int x = 0;
        int y = 0;
 
        // Ищем максимум, минимум и координаты
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (temperature[i][j] > max) {
                    max = temperature[i][j];
                    x = i;
                    y = j;
                }
 
                if (temperature[i][j] < min) {
                    min = temperature[i][j];
                }
            }
        }
 
        // Выводим максимум и координаты
        out.println("Максимальная температура: " + max);
        out.println("Координаты (строка, столбец): "
                    + (x + 1) + " " + (y + 1));
 
        // Символы тепловой карты
        char[] signs = {'*', 'o', '+', '-', '.'};
 
        out.println("Тепловая карта:");
 
        // Строим тепловую карту
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                int level = 0;
 
                // Проверяем, что диапазон не равен нулю
                if (max != min) {
                    level = (int) ((temperature[i][j] - min)
                                  * 5 / (max - min));
 
                    // У максимума получается уровень 5
                    if (level == 5) {
                        level = 4;
                    }
                }
 
                out.print(signs[level] + " ");
            }
 
            out.println();
        }
 
        // Выводим разность температур
        out.println("Разница максимума и минимума: "
                    + (max - min));
    }
}
```
 
### 6. Анализ правильности решения
 
Программа проверена на различных наборах данных.
 
#### Тест 1. Сортировка строк
 
**Input:**
 
```text
3 3
10 20 30
5 15 25
2 18 25
```
 
**Output:**
 
```text
Максимальная температура: 30.0
Координаты (строка, столбец): 3 3
Тепловая карта:
* + .
* + .
o - .
Разница максимума и минимума: 28.0
```
 
**Объяснение:**
 
Строки располагаются по возрастанию средних
температур. Две строки с одинаковыми суммами
и максимумами сохраняют первоначальный порядок.
 
Максимум 30 находится в третьей строке,
третьем столбце.
 
#### Тест 2. Равные средние, разные максимумы
 
**Input:**
 
```text
3 2
0 20
5 15
7 13
```
 
**Output:**
 
```text
Максимальная температура: 20.0
Координаты (строка, столбец): 3 2
Тепловая карта:
o -
o -
* .
Разница максимума и минимума: 20.0
```
 
**Объяснение:**
 
Все три строки имеют среднее значение 10.
Поэтому они сортируются по максимумам:
13, 15 и 20.
 
#### Тест 3. Равные суммы и максимумы
 
**Input:**
 
```text
2 3
0 6 6
6 0 6
```
 
**Output:**
 
```text

Координаты (строка, столбец): 1 2
Тепловая карта:
* . .
. * .
Разница максимума и минимума: 6.0
```
 
**Объяснение:**
 
Обе строки имеют одинаковые суммы и максимумы.
Поэтому программа сохраняет их исходный порядок.
 
При нескольких одинаковых максимумах
запоминается первая найденная позиция.
 
#### Тест 4. Одинаковые температуры

```text
* *
Разница максимума и минимума: 0.0
```
 
**Объяснение:**
 
Все температуры одинаковые.
 
Разность максимума и минимума равна нулю.
Программа не выполняет деление на ноль
и выводит символ * для всех элементов.

**Объяснение:**
 
Максимальная температура равна 10,

Программа правильно обрабатывает
отрицательные значения.
 
#### Тест 6. Один элемент массива
